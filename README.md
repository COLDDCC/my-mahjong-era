# My Mahjong Era

An independent editorial and practical hub for American Mahjong beginners, Mahjong culture around the world, social play, and free tools.

## Development

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

Framework preset: Astro. Build command: `npm run build`. Output directory: `dist`. Node version: 22.

The site uses original copy and no third-party product photos or trademarks. This is not an official partner of Oh My Mahjong.

**Before launch:** Confirm domain ownership, complete trademark review, replace placeholder contact, test the build and browser interactions, and verify mobile layouts.
